What we do

OTA 운영의 반복 작업을
플랫폼이 대신합니다

펌웨어를 올리는 순간부터 차량에 도달할 때까지, 사람이 손으로 하던 운영 작업을 자동화했습니다.

안정적인 펌웨어 배포

S3 + CloudFront CDN으로 대용량 펌웨어를 빠르고 안정적으로 전달합니다.

코드로 관리하는 인프라

Terraform과 Ansible로 네트워크, 클러스터, DB를 선언형으로 구성하고 재현합니다.

GitOps 자동 배포

Jenkins로 빌드하고 Argo CD가 Git 상태를 클러스터에 동기화합니다.

한눈에 보는 관측성

Prometheus · Grafana · Loki로 메트릭과 로그를 통합해 장애를 빠르게 찾습니다.

이중화 · 오토스케일링

멀티 클러스터 구성과 부하 테스트 기반 오토스케일링으로 트래픽 폭주에 대비합니다.

내부망 보안 설계

S3 · RDS를 VPC 프라이빗 서브넷에 두고 온프레미스와 Site-to-Site VPN으로 연결합니다.

Architecture

하이브리드 클라우드 아키텍처

온프레미스 클러스터와 AWS를 VPN으로 묶고, 배포와 관측을 하나의 파이프라인으로 연결했습니다.
